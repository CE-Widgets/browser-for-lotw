# Browser for LoTW

Browser for LoTW is an Android application for downloading, browsing, sorting, and filtering data from ARRL Logbook of The World (LoTW).

## Features

- Download QSOs and QSLs directly from LoTW
- Browse downloaded data locally
- Sort by any displayed column
- Powerful regular expression filtering
- Offline access after download
- Demo mode included
